⚙️Bài 1 — Config: đọc trước khi load trọng số

Quy tắc vàng: đọc config + giấy phép trước, tải trọng số sau. Trọng số nặng ~1 GB — tải nhầm model là mất công. Config cho biết mọi thứ cần thiết:

MụcSố liệu thật
Kiến trúcQwen2ForCausalLM
Số lớp / Hidden size24 lớp / 896
Attention head / KV head14 / 2 → GQA
Cửa sổ ngữ cảnh32.768 token (prompt + output cộng lại)
Dtype gốcbfloat16
Tổng params (đếm thật)494.032.768 (~0,494 tỉ)
VRAM bf16 ước lượng0,99 GB (params × 2 byte, chưa KV cache)

GQA là gì? 14 head dùng chung 2 "kho" key-value

👥 Ví dụ — 14 nhân viên, 2 tủ hồ sơ: attention thường (MHA) mỗi head có tủ riêng (14 tủ). GQA cho 7 head dùng chung 1 tủ (14 head / 2 tủ) → KV cache nhẹ hơn 7 lần, tốc độ sinh nhanh hơn, chất lượng gần như giữ nguyên. Đây là lý do model nhỏ vẫn chạy mượt.

🔤Bài 2 — Tokenizer: model không đọc chữ, nó đọc id

Câu văn phải qua tokenizer để thành dãy số (id) rồi model mới xử lý được. Mỗi từ có thể bị chẻ thành nhiều mảnh — và số mảnh = số token chính là thứ tính tiền và tính context.

🔤 Thử ngay: xem model chẻ câu ra sao (số liệu thật)

Chọn một câu — token và id là kết quả encode thật bằng tokenizer Qwen2.5:

CâuTokenNhận xét
"Thu do cua Phap la gi?"9không dấu, bị chẻ vụn ("c" + "ua")
"Thủ đô của Pháp là gì?"8có dấu: ít token hơn!
"What is the capital of France?"7tiếng Anh: mỗi từ ~1 token
"Giai thich transformer trong mot cau."11"Giai" → 'G','ia','i' — chẻ nát
"Giải thích transformer trong một câu."8có dấu lại gọn hơn

🔑 3 chi tiết "nhỏ mà quan trọng"

  • eos = <|im_end|> (151645) — token "hết lượt nói", model sinh ra nó là dừng. pad = <|endoftext|> (151643).
  • Vocab: len(tok) = 151.665, trong khi config ghi vocab_size 151.936 — chênh lệch do vocab có token dự phòng chưa dùng.
  • add_special_tokens=True và False cho kết quả giống hệt nhau: Qwen không tự thêm BOS/EOS khi encode (khác BERT có [CLS]/[SEP]). Decode ngược câu có khoảng trắng đầu + dấu câu: khớp 100%.

💬Bài 3 — Chat template: đóng khung hội thoại

Bản Instruct được SFT bằng đúng một định dạng hội thoại. Đưa prompt trần vào là nói sai "ngôn ngữ" model đã học — nó vẫn trả lời, nhưng kém hẳn.

Prompt trần (cách A — sai với bản instruct)

'Thu do cua Phap la gi?'

Qua chat template (cách B — đúng định dạng SFT)

<|im_start|>system
Ban la tro ly huu ich, tra loi ngan gon.<|im_end|>
<|im_start|>user
Thu do cua Phap la gi?<|im_end|>
<|im_start|>assistant

Chuỗi kết thúc bằng <|im_start|>assistant = "đến lượt model nói". Đổi system prompt thành giọng cướp biển thì chỉ phần nội dung system thay đổi, khung thẻ giữ nguyên → system prompt thực chất chỉ là một phần của prompt, không phải công tắc đặc biệt nào.

🎭 Ví dụ — Kịch bản sân khấu: template là khung kịch bản ghi rõ ai nói lúc nào: system (đạo diễn dặn dò) → user (khán giả hỏi) → assistant (diễn viên trả lời). Prompt trần là diễn viên không có kịch bản: vẫn nói được, nhưng dễ lạc vai.

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""Lab load model that: Qwen2.5-0.5B-Instruct (Day 15 - buoi toi).

4 bai:
  1. Doc config truoc khi load trong so (kien truc, context, VRAM).
  2. Tokenizer: tieng Viet vs tieng Anh, special token, decode nguoc.
  3. Chat template: prompt tran vs qua template, system prompt.
  4. Sinh van ban: greedy vs sampling (cung prompt, doi 1 bien).

Moi truong: CPU-only (VM nay khong co GPU) nen load float32, giam
max_new_tokens xuong 30 cho nhanh (dung nhu Bay 3 cua de bai).

Cach chay (dung venv rieng, tranh loi ENOSPC o system pip):
    ~/workspace/venvs/day15/bin/python load_model_lab.py

Chu y checklist 7 diem: docstring khop code, device dung cho (tensor
ve model.device), do thoi gian bang perf_counter, khong file I/O
gia dinh shape.
"""

import time

import os

import torch
from transformers import (AutoConfig, AutoModelForCausalLM,
                          AutoTokenizer)

# Model tai ve qua ModelScope (HF CDN bi chan toc do qua proxy cua VM).
# Thu muc local da du: config.json, model.safetensors, tokenizer.
MODEL = os.path.expanduser(
    "~/.cache/modelscope/models/Qwen--Qwen2.5-0.5B-Instruct/"
    "snapshots/master")
MAX_NEW_TOKENS = 30  # CPU: giam tu 60 xuong 30 cho nhanh (Bay 3)


def bai1_config():
    """Bai 1: doc config truoc khi load trong so.

    Quy tac vang: doc config + giay phep truoc, tai trong so sau.
    """
    print("=" * 72)
    print("BAI 1 - Doc config")
    print("=" * 72)
    cfg = AutoConfig.from_pretrained(MODEL)
    print("Kien truc:", cfg.architectures)
    print("So lop:", cfg.num_hidden_layers)
    print("Hidden size:", cfg.hidden_size)
    print("So head / KV head:", cfg.num_attention_heads, "/",
          cfg.num_key_value_heads)
    print("Cua so ngu canh:", cfg.max_position_embeddings)
    print("Dtype:", cfg.torch_dtype)
    # GQA hay MHA? KV head < attention head => Grouped-Query Attention.
    gqa = cfg.num_key_value_heads < cfg.num_attention_heads
    print("Ket luan:", "GQA (KV head it hon attention head, KV cache "
          f"nhe hon {cfg.num_attention_heads // cfg.num_key_value_heads}x)"
          if gqa else "MHA thuong")
    # Uoc luong VRAM bf16 day du se tinh o main() sau khi load model.
    return cfg


def bai2_tokenizer(tok):
    """Bai 2: tokenizer - model khong doc chu, no doc id."""
    print("\n" + "=" * 72)
    print("BAI 2 - Tokenizer")
    print("=" * 72)
    texts = ["Thu do cua Phap la gi?",
             "What is the capital of France?",
             "Toi yeu AI",
             "Giai thich transformer trong mot cau."]
    for text in texts:
        ids = tok.encode(text)
        print(f"TEXT: {text}")
        print(f"  tokens: {tok.convert_ids_to_tokens(ids)}")
        print(f"  ids   : {ids} | so token: {len(ids)}")
    print("eos:", tok.eos_token, tok.eos_token_id)
    print("pad:", tok.pad_token, tok.pad_token_id)
    print("Kich thuoc vocab:", len(tok))
    # add_special_tokens True vs False: Qwen khong them token dac biet
    # vao dau/cuoi khi encode thuong (khac BERT co [CLS]/[SEP]).
    t = "Thu do cua Phap la gi?"
    with_sp = tok.encode(t, add_special_tokens=True)
    without_sp = tok.encode(t, add_special_tokens=False)
    print(f"add_special_tokens=True : {with_sp}")
    print(f"add_special_tokens=False: {without_sp}")
    print("Khac nhau:", with_sp != without_sp)
    # Decode nguoc (cau co dau cau + khoang trang dau cau).
    t2 = "  Hello, world!"
    ids2 = tok.encode(t2)
    print(f"Decode nguoc {t2!r} -> {tok.decode(ids2)!r} "
          f"(khop: {tok.decode(ids2) == t2})")

def generate_and_time(model, tok, prompt, max_new_tokens, **gen_kwargs):
    """Sinh 1 lan, do thoi gian bang perf_counter.

    Returns:
        Tuple (text_sinh, giay).
    """
    inputs = tok(prompt, return_tensors="pt").to(model.device)
    n_in = inputs["input_ids"].shape[1]
    t0 = time.perf_counter()
    out = model.generate(**inputs, max_new_tokens=max_new_tokens,
                         **gen_kwargs)
    dt = time.perf_counter() - t0
    text = tok.decode(out[0][n_in:], skip_special_tokens=True)
    return text, dt


def bai4_generate(model, tok):
    """Bai 4: greedy vs sampling tren CUNG prompt (doi 1 bien).

    Giu nguyen prompt template, chi doi decoding - dung nguyen tac
    ablation 1 bien cua tuan truoc.
    """
    print("\n" + "=" * 72)
    print("BAI 4 - Greedy vs sampling")
    print("=" * 72)
    messages = [
        {"role": "system",
         "content": "Ban la tro ly huu ich, tra loi ngan gon."},
        {"role": "user",
         "content": "Viet mot cau gioi thieu ve tri tue nhan tao."},
    ]
    prompt = tok.apply_chat_template(
        messages, tokenize=False, add_generation_prompt=True)
    # Greedy: chay 3 lan phai cho CUNG 1 ket qua (deterministic).
    print("=== GREEDY (3 lan) ===")
    for i in range(3):
        text, dt = generate_and_time(model, tok, prompt, MAX_NEW_TOKENS,
                                     do_sample=False)
        print(f"  lan {i + 1} ({dt:.1f}s): {text}")
    # Sampling: chay 3 lan cho 3 ket qua KHAC nhau.
    print("=== SAMPLING temp=0.8, top-p=0.9 (3 lan) ===")
    for i in range(3):
        text, dt = generate_and_time(model, tok, prompt, MAX_NEW_TOKENS,
                                     do_sample=True, temperature=0.8,
                                     top_p=0.9)
        print(f"  lan {i + 1} ({dt:.1f}s): {text}")
    # Temperature cao 1.5: lieu hon hay loan hon?
    print("=== SAMPLING temp=1.5 (1 lan) ===")
    text, dt = generate_and_time(model, tok, prompt, MAX_NEW_TOKENS,
                                 do_sample=True, temperature=1.5,

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""Bo sung Bai 4: sinh lai voi prompt TIENG VIET CO DAU.

Ly do: ban dau script dung prompt khong dau (theo quy uoc comment
khong dau) nen model hieu sai - greedy tu choi, sampling lac sang
'trang web'. Chay lai voi prompt goc co dau cua de bai de kiem
chung: chat luong co tot hon khong, va 3 tinh chat (greedy on
dinh, sampling da dang, prompt tran te hon) co con dung khong.

Prompt goc cua de bai:
  system: "Ban la tro ly huu ich, tra loi ngan gon."
  user: "Viet mot cau gioi thieu ve tri tue nhan tao."
(duoi day viet co dau day du, vi day la DU LIEU chay model, khong
phai comment code).
"""

import os
import time

import torch
from transformers import AutoModelForCausalLM, AutoTokenizer

MODEL = os.path.expanduser(
    "~/.cache/modelscope/models/Qwen--Qwen2.5-0.5B-Instruct/"
    "snapshots/master")
MAX_NEW_TOKENS = 30


def gen(model, tok, prompt, **kwargs):
    """Sinh 1 lan, do thoi gian bang perf_counter."""
    inputs = tok(prompt, return_tensors="pt").to(model.device)
    n_in = inputs["input_ids"].shape[1]
    t0 = time.perf_counter()
    out = model.generate(**inputs, max_new_tokens=MAX_NEW_TOKENS,
                         **kwargs)
    dt = time.perf_counter() - t0
    return tok.decode(out[0][n_in:], skip_special_tokens=True), dt


def main():
    """Load model 1 lan, sinh 3 kieu voi prompt co dau."""
    tok = AutoTokenizer.from_pretrained(MODEL)
    model = AutoModelForCausalLM.from_pretrained(
        MODEL, dtype=torch.float32)
    messages = [
        {"role": "system",
         "content": "Bạn là trợ lý hữu ích, trả lời ngắn gọn."},
        {"role": "user",
         "content": "Viết một câu giới thiệu về trí tuệ nhân tạo."},
    ]
    prompt = tok.apply_chat_template(
        messages, tokenize=False, add_generation_prompt=True)
    print("=== TEMPLATE + GREEDY (co dau) ===")
    text, dt = gen(model, tok, prompt, do_sample=False)
    print(f"  ({dt:.1f}s): {text}")
    print("=== TEMPLATE + SAMPLING temp=0.8 (co dau) ===")
    text, dt = gen(model, tok, prompt, do_sample=True,
                   temperature=0.8, top_p=0.9)
    print(f"  ({dt:.1f}s): {text}")
    print("=== PROMPT TRAN + GREEDY (co dau, de so sanh) ===")
    text, dt = gen(model, tok, "Viết một câu giới thiệu về "
                   "trí tuệ nhân tạo.", do_sample=False)
    print(f"  ({dt:.1f}s): {text}")


if __name__ == "__main__":
    main()
