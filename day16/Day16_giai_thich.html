Day 16 — Lab SFT GPT-2 124M
dạy model cách trả lời

Pretrain dạy model kiến thức (đoán từ tiếp theo). SFT dạy model hành vi: thấy câu hỏi thì trả lời, trả lời xong thì dừng. Lab này làm đúng việc đó trên GPT-2 124M với chỉ 14 mẫu tiếng Việt — và kết quả thì không tô hồng.

Số liệu trong bài là kết quả chạy thật (VM CPU-only, torch 2.14.1+cpu, transformers 5.20.2, venv day15).

🍿 Tóm tắt 30 giây 🎭 Masking 🧱 Padding 🏋️ Train trước–sau 🧪 Ablation 📈 10 epoch 💡 Kết luận thật 📜 Source code

🍿Tóm tắt 30 giây cho người ngoại đạo

GPT-2 chỉ biết tiếng Anh — hỏi tiếng Việt thì nó sinh "tiếng Việt rác". SFT là quá trình uốn nắn hành vi: cho model xem mẫu "hỏi → đáp" để nó học khuôn mẫu trả lời. Lab gồm 3 bài + 1 ablation + 1 bản train dài:

🎭 Bài 1 — Masking

Che prompt bằng -100, chỉ tính loss trên đáp án. Assert PASS mới được train — sai là dừng ngay.

🧱 Bài 2 — Padding

Token thật chỉ 53%, đệm lãng phí 47% — gần nửa compute đổ vào đệm. Packing ước lượng còn 7,6%.

🏋️ Bài 3 — Train 2 epoch

Loss 3,3230 → 2,3886. Hành vi đổi: rác → echo lại prompt (chưa ra đáp án đúng).

🧪 Ablation — Tắt masking

Chỉ đổi 1 biến: loss cao hơn, sinh lặp khuôn mẫu "ả lời: ả lời:" — chứng minh masking quyết định.

📈 10 epoch

Val loss đáy ở epoch 6 rồi tăng → overfit. Định dạng học được (ngắn + dừng), nội dung sụp đổ về "Tokyo.".

🎓 Ví dụ — Dạy trẻ trả lời: pretrain như cho trẻ đọc cả thư viện (biết nhiều chữ). SFT như luyện thi vấn đáp: thầy hỏi → trò đáp → thầy chấm chỉ phần đáp. Masking chính là "chỉ chấm phần đáp, không chấm phần câu hỏi". Không masking thì như chấm cả câu hỏi — trò học thuộc câu hỏi thay vì học trả lời.

🎭Bài 1 — Masking: chỉ chấm phần đáp án

Mỗi mẫu SFT = prompt + đáp án, token hóa riêng rẽ rồi nối lại. Với masking BẬT, labels ở vị trí prompt bị che bằng -100 (PyTorch bỏ qua khi tính loss) — model chỉ bị "chấm điểm" trên đáp án.

🎭 Thử ngay: bật/tắt masking trên mẫu 0 (số thật)

Mẫu 0: "Thủ đô của Việt Nam là gì?" → "Hà Nội." = 54 token (prompt 45 + đáp án 9). Mỗi ô vuông là 1 token:

✅ Assert kiểm chứng — PASS mới được train

  • Mọi label ở vị trí prompt đều là -100 ✓
  • Label ở vị trí đáp án bằng đúng token thật ✓
  • Kết quả: "Masking OK. Mẫu 0 có 54 token, trong đó 9 token tính loss."
  • Edge case: instruction/output rỗng → ValueError rõ ràng ("instruction va output khong duoc rong.") — vì đáp án rỗng sẽ làm labels toàn -100, loss thành NaN âm thầm. Chặn sớm, đừng để NaN đi xa.
📝 Ví dụ — Chấm bài thi: đề bài (prompt) là thứ thầy cho, đáp án mới là thứ trò viết. Chấm cả đề lẫn đáp thì trò chỉ cần học thuộc đề là được điểm — đó chính là cái giá của việc tắt masking (xem phần ablation).

🧱Bài 2 — Padding: gần nửa compute đổ vào đệm

14 mẫu dài ngắn khác nhau (mẫu dài nhất 175 token — email dài, GPT-2 BPE tiếng Anh chẻ tiếng Việt rất nhỏ). Gom thành batch thì mẫu ngắn phải đệm pad cho bằng mẫu dài — và đệm cũng tốn compute.

🧱 Token thật vs token đệm (số thật)

Tổng token kể cả padding: 2450 = token thật 1301 (53%) + token đệm 1149 (47%).

💡 Packing — cách giảm lãng phí: thay vì đệm từng mẫu, xếp các mẫu nối tiếp nhau cho đầy sequence 128 token → chỉ còn 11 sequence, token đệm chỉ còn 107 (7,6%) thay vì 47%. Như xếp hành lý: thay vì mỗi vali một ngăn đệm, xếp đồ liền nhau cho đầy vali rồi mới sang vali mới.

🏋️Bài 3 — Train 2 epoch: từ "rác" sang "echo"

Split: 11 train / 3 val (val = 3 mẫu dịch cuối). LR 5e-5, batch 4, 2 epoch theo đúng đề bài. Sinh greedy 30 token trên cùng 5 prompt cố định, cùng template train — đổi template giữa chừng là đổi luôn bài kiểm tra.

def format_prompt(instruction):
    """Rap prompt theo template co dinh cua lab.

    Template nay dung cho CA train VA sinh - khong doi giua
    chung, ke ca dau xuong dong va token ket thuc.
    """
    return f"Câu hỏi: {instruction}\nTrả lời: "


def encode_example(item, tok, mask_prompt=True):
    """Ma hoa 1 mau SFT thanh (input_ids, labels).

    Prompt va dap an token hoa RIENG RE, noi lai thanh input_ids.
    Neu mask_prompt=True: labels che prompt bang -100, chi tinh
    loss tren dap an (chuan SFT). Neu False (ablation): labels =
    input_ids, tinh loss ca prompt.

    Args:
        item: dict {"instruction": ..., "output": ...}.
        tok: tokenizer GPT-2 (pad = eos).
        mask_prompt: True = che prompt, False = khong che.

    Returns:
        Tuple (input_ids, labels) la 2 list int.

    Raises:
        ValueError: neu instruction hoac output rong (dap an rong
            se lam labels toan -100, loss thanh NaN).
    """
    if not item["instruction"] or not item["output"]:
        raise ValueError("instruction va output khong duoc rong.")
    prompt = format_prompt(item["instruction"])
    answer = item["output"] + tok.eos_token
    prompt_ids = tok(prompt, add_special_tokens=False)["input_ids"]
    answer_ids = tok(answer, add_special_tokens=False)["input_ids"]
    input_ids = prompt_ids + answer_ids
    if mask_prompt:
        labels = [-100] * len(prompt_ids) + answer_ids
    else:
        labels = list(input_ids)
    return input_ids, labels


def verify_masking(tok):
    """Kiem chung masking: PASS het moi duoc sang Bai 2.

    Assert: moi label o vi tri prompt la -100, label o vi tri
    dap an bang dung token that.
    """
    ids, labels = encode_example(DATA[0], tok, mask_prompt=True)
    prompt_len = len(tok(format_prompt(DATA[0]["instruction"]),
                         add_special_tokens=False)["input_ids"])
    assert all(l == -100 for l in labels[:prompt_len]), \
        "Prompt chua duoc che het!"
    assert labels[prompt_len:] == ids[prompt_len:], \
        "Label dap an phai bang token that!"
    n_loss = sum(1 for l in labels if l != -100)
    print(f"Masking OK. Mau 0 co {len(ids)} token, trong do "
          f"{n_loss} token tinh loss.")
    print(tok.decode(ids))
    # Edge case: dap an rong phai bao loi ro rang, khong NaN am tham.
    try:
        encode_example({"instruction": "Hoi?", "output": ""}, tok)
        print("CANH BAO: output rong khong bi chan!")
    except ValueError as exc:
        print(f"Edge case output rong: chan dung ({exc})")


def measure_padding(tok):
    """Bai 2: do ti le token that / token dem cua toan bo DATA."""
    encoded = [encode_example(d, tok) for d in DATA]
    max_len = max(len(ids) for ids, _ in encoded)
    total = len(encoded) * max_len
    real = sum(len(ids) for ids, _ in encoded)
    print(f"Mau dai nhat: {max_len} token | "
          f"Tong token (ke ca padding): {total}")
    print(f"Token that: {real} ({real / total:.0%}) | "
          f"Token dem lang phi: {total - real} "
          f"({1 - real / total:.0%})")
    # Uoc luong packing: xep cac mau noi tiep cho day sequence 128
    # token, chi thua 1 doan padding cuoi cung (< 128 token).
    n_seq = (real + 127) // 128
    packed_total = n_seq * 128
    print(f"Uoc luong packing (seq 128): {n_seq} sequence, "
          f"token dem chi con {packed_total - real} "
          f"({(packed_total - real) / packed_total:.1%}) "
          f"thay vi {1 - real / total:.0%}.")
    return encoded


class SFTDataset(Dataset):
    """Dataset SFT: encode san toan bo mau luc khoi tao."""

    def __init__(self, items):
        """Args: items la list (input_ids, labels) da encode."""
        self.items = items

    def __len__(self):
        """Tra ve so mau."""
        return len(self.items)

    def __getitem__(self, i):
        """Tra ve dict input_ids/labels cua mau thu i."""
        ids, labels = self.items[i]
        return {"input_ids": ids, "labels": labels}


def collate(batch, pad_id):
    """Dem batch ve cung do dai: pad token + nhan -100.

    Attention mask = 1 cho token that, 0 cho padding.
    """
    max_len = max(len(b["input_ids"]) for b in batch)
    input_ids, labels, attn = [], [], []
    for b in batch:
        pad = max_len - len(b["input_ids"])
        input_ids.append(b["input_ids"] + [pad_id] * pad)
        labels.append(b["labels"] + [-100] * pad)
        attn.append([1] * len(b["input_ids"]) + [0] * pad)
    return {"input_ids": torch.tensor(input_ids),
            "labels": torch.tensor(labels),
            "attention_mask": torch.tensor(attn)}


def train_model(tok, train_items, tag):
    """Train GPT-2 tu dau (load lai trong so goc) va tra ve model.

    Seed lai truoc moi lan train de 2 ban (masking bat/tat) co
    cung thu tu shuffle va dropout - chi khac 1 bien masking
    (labels da encode san trong train_items truoc khi goi ham).
    """
    torch.manual_seed(SEED)
    model = AutoModelForCausalLM.from_pretrained(MODEL_DIR)
    model.to(DEVICE)
    model.config.pad_token_id = tok.pad_token_id
    loader = DataLoader(
        SFTDataset(train_items), batch_size=BATCH_SIZE, shuffle=True,
        collate_fn=lambda b: collate(b, tok.pad_token_id),
        generator=torch.Generator().manual_seed(SEED))
    opt = torch.optim.AdamW(model.parameters(), lr=LEARNING_RATE)
    model.train()
    t0 = time.perf_counter()
    epoch_losses = []
    for epoch in range(EPOCHS):
        total_loss, steps = 0.0, 0
        for batch in loader:
            batch = {k: v.to(DEVICE) for k, v in batch.items()}
            out = model(**batch)
            out.loss.backward()
            opt.step()
            opt.zero_grad()
            total_loss += out.loss.item()
            steps += 1
        avg = total_loss / steps
        epoch_losses.append(avg)
        print(f"  [{tag}] Epoch {epoch + 1}: train loss = {avg:.4f}")
    dt = time.perf_counter() - t0
    print(f"  [{tag}] Train xong trong {dt:.1f}s "
          f"({EPOCHS} epoch, {len(train_items)} mau).")
    return model, epoch_losses


@torch.no_grad()
def generate(model, tok, prompt):
    """Sinh greedy 30 token theo dung template train."""
    ids = tok(prompt, return_tensors="pt").to(DEVICE)
    out = model.generate(**ids, max_new_tokens=MAX_NEW_TOKENS,
                         do_sample=False,
                         pad_token_id=tok.eos_token_id)
    return tok.decode(out[0][ids["input_ids"].shape[1]:],
                      skip_special_tokens=True)


def evaluate(model, tok, title):

    model.eval()
    for p in PROMPTS:
        print("PROMPT:", p.replace("\n", " / "))
        print("->", generate(model, tok, p))

#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""Bo sung Day 16: train MASKING 10 epoch de kiem chung gia thuyet.

Ket qua ban 2 epoch: loss giam (3.32 -> 2.39) nhung model chi
ECHO lai prompt (vd: "u do cua Viet Nam la gi?") thay vi tra loi
"Ha Noi.". Gia thuyet: 2 epoch x 11 mau la QUA IT cho model
tieng Anh hoc dap an tieng Viet - model moi hoc duoc hanh vi de
nhat la copy token tu prompt.

Script nay train them 10 epoch (cung du lieu, cung LR, cung
seed) + do val loss moi epoch de xem: (a) model co nho duoc dap
an khong, (b) val loss co bat dau tang (overfit) khong.

Neu 10 epoch cho dap an dung -> gia thuyet dung, 2 epoch chi la
chua du. Neu van echo -> co van de sau hon, can dieu tra.
"""

import os
import time

import torch
from torch.utils.data import DataLoader

from sft_lab import (BATCH_SIZE, DATA, LEARNING_RATE, MODEL_DIR,
                     PROMPTS, SEED, SFTDataset, collate,
                     encode_example, evaluate)

DEVICE = "cuda" if torch.cuda.is_available() else "cpu"
EPOCHS_LONG = 10


@torch.no_grad()
def val_loss(model, tok, val_items):
    """Loss trung binh tren tap val (labels da masking san)."""
    model.eval()
    loader = DataLoader(SFTDataset(val_items), batch_size=4,
                        collate_fn=lambda b: collate(b,
                                                     tok.pad_token_id))
    total, steps = 0.0, 0
    for batch in loader:
        batch = {k: v.to(DEVICE) for k, v in batch.items()}
        total += model(**batch).loss.item()
        steps += 1
    model.train()
    return total / steps


def main():
    """Train 10 epoch, in train/val loss moi epoch, sinh 5 prompt."""
    from transformers import AutoModelForCausalLM, AutoTokenizer

    print(f"torch {torch.__version__} | device: {DEVICE}")
    tok = AutoTokenizer.from_pretrained(MODEL_DIR)
    tok.pad_token = tok.eos_token
    n_val = max(1, round(len(DATA) * 0.2))
    train_data, val_data = DATA[:-n_val], DATA[-n_val:]
    train_items = [encode_example(d, tok, mask_prompt=True)
                   for d in train_data]
    val_items = [encode_example(d, tok, mask_prompt=True)
                 for d in val_data]
    torch.manual_seed(SEED)
    model = AutoModelForCausalLM.from_pretrained(MODEL_DIR).to(DEVICE)
    model.config.pad_token_id = tok.pad_token_id
    loader = DataLoader(
        SFTDataset(train_items), batch_size=BATCH_SIZE, shuffle=True,
        collate_fn=lambda b: collate(b, tok.pad_token_id),
        generator=torch.Generator().manual_seed(SEED))
    opt = torch.optim.AdamW(model.parameters(), lr=LEARNING_RATE)
    model.train()
    t0 = time.perf_counter()
    for epoch in range(EPOCHS_LONG):
        total_loss, steps = 0.0, 0
        for batch in loader:
            batch = {k: v.to(DEVICE) for k, v in batch.items()}
            out = model(**batch)
            out.loss.backward()
            opt.step()
            opt.zero_grad()
            total_loss += out.loss.item()
            steps += 1
        vl = val_loss(model, tok, val_items)
        print(f"Epoch {epoch + 1}: train loss = "
              f"{total_loss / steps:.4f} | val loss = {vl:.4f}")
    print(f"Train xong trong {time.perf_counter() - t0:.1f}s "
          f"({EPOCHS_LONG} epoch, {len(train_data)} mau).")
    evaluate(model, tok, "SAU 10 EPOCH (masking BAT)")


if __name__ == "__main__":
    main()
