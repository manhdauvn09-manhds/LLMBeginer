LoRA là dán giấy note lên từng trang: sách gốc nguyên vẹn, note có thể bóc ra (merge/unmerge) bất cứ lúc nào. Rank = độ dày của tờ note: note càng dày càng ghi được nhiều, nhưng đến một lúc dày thêm cũng không giúp hiểu hơn.

🧩LoRA là gì: W + BA, với B khởi tạo bằng 0

Với mỗi ma trận trọng số gốc W (đóng băng), LoRA cộng thêm một "bản vá" có hạng thấp: ΔW = B × A, trong đó A (r × d_in) khởi tạo ngẫu nhiên, B (d_out × r) khởi tạo bằng 0. Vì B = 0 nên lúc mới bắt đầu, ΔW = 0 — model chưa bị "phá" gì cả, rồi mới học dần từ 0.

W' = W + (α/r) × B × A W đóng băng · chỉ A và B được train · α/r = 2 cố định trong cả lab
🎚️ Ví dụ — Nút chỉnh âm lượng: rank r giống như số nấc chỉnh của một nút: r = 4 là nút 4 nấc (chỉnh thô), r = 16 là nút 16 nấc (chỉnh tinh hơn). Nhưng nếu bài nhạc chỉ cần chỉnh thô thì nút 16 nấc cũng không hay hơn bao nhiêu — và đó chính là điều ablation hôm nay đo được.

⚠️ Quy tắc "2 model bằng tham số" KHÔNG áp dụng ở đây

Tuần trước (Day 13) ta bắt 2 model phải bằng params để ablation sạch 1 biến. Ở đây rank chính là biến độc lập — số tham số train được KHÁC NHAU giữa các rank là đúng ý đồ, không phải lỗi. Điều giữ cố định là mọi thứ khác: dataset, split, seed (42), epoch (2), LR (1e-4), batch (4), tỉ lệ α/r = 2, decoding greedy 30 token.

📊 Val loss theo rank — giảm đều, nhưng giảm ít

🔗Bài 3 — Merge adapter r = 16: cộng note vào sách, chữ có lệch không?

Sau khi chọn rank tốt nhất (r = 16 theo val loss), lab merge adapter vào model gốc bằng merge_and_unload() — tức cộng ΔW = BA vào W, rồi kiểm tra đầu ra trước/sau merge có giống nhau không.

💾 Adapter chỉ 2,37 MB

So với ~500 MB của GPT-2 đầy đủ → tiết kiệm ~99,5%. Gửi adapter qua email được, gửi cả model thì không.

✅ Merge check: 6/6 giống hệt

Cả 6 prompt đánh giá cho đầu ra greedy giống hệt trước/sau merge trong lần chạy này.

🔬 Trainer soi sâu hơn: lệch logits tối đa 3,4e-04

Đúng mức làm tròn float32 khi cộng BA vào W. Nếu cộng sai chiều (bẫy Conv1D của GPT-2) hoặc sai scale thì logits đã lệch hẳn. Merge đúng.

Sơ đồ: W gốc + adapter = model đã merge. Vì merge chỉ là phép cộng nên đầu ra gần như không đổi — sai số duy nhất là làm tròn float32.
🖊️ Ví dụ — Dán note rồi viết đè lên sách: merge là lúc ta quyết định viết nội dung giấy note đè thẳng vào trang sách, rồi vứt tờ note đi. Sách vẫn đọc y như lúc dán note — vì nội dung note không đổi, chỉ đổi chỗ chứa nó.

def format_prompt(instruction):
    """Rap prompt theo template co dinh cua lab."""
    return f"Câu hỏi: {instruction}\nTrả lời: "


def encode_example(item, tok):
    """Ma hoa 1 mau SFT: labels che prompt bang -100.

    Raises:
        ValueError: neu instruction hoac output rong.
    """
    if not item["instruction"] or not item["output"]:
        raise ValueError("instruction va output khong duoc rong.")
    prompt = format_prompt(item["instruction"])
    answer = item["output"] + tok.eos_token
    prompt_ids = tok(prompt, add_special_tokens=False)["input_ids"]
    answer_ids = tok(answer, add_special_tokens=False)["input_ids"]
    input_ids = prompt_ids + answer_ids
    labels = [-100] * len(prompt_ids) + answer_ids
    # [TRAINER] Dung cho nguy hiem nhat cua SFT: token cuoi cua
    # answer la EOS va EOS NAM TRONG labels -> model duoc hoc cach
    # dung. Trainer kiem chung tren ca 32 mau: label cuoi cua moi
    # mau deu la EOS (50256). Day 16 ban cung lam dung cho nay.
    return input_ids, labels


def stratified_split(data, seed=SEED, val_frac=0.2):
    """Chia train/val phan tang theo kind (80/20 moi kind).

    Xao tron co seed co dinh trong tung kind. Kind co < 5 mau
    thi khong lay val (tranh val chi co 1 mau dai dien kem).
    """
    rng = random.Random(seed)
    by_kind = {}
    for item in data:
        by_kind.setdefault(item["kind"], []).append(item)
    train, val = [], []
    for kind, items in by_kind.items():
        items = items[:]
        rng.shuffle(items)
        if len(items) >= 5:
            n_val = max(1, int(len(items) * val_frac))
        else:
            n_val = 0
        val.extend(items[:n_val])
        train.extend(items[n_val:])
    # [TRAINER] Bai hoc Day 16 da thanh phan xa: split phan tang co
    # seed - trainer kiem doc lap: train 28 mau (dung 7/kind), val 4
    # mau (dung 1/kind), khong trung instruction giua 2 tap. Day la
    # khac biet lon nhat so voi Day 16 (val toan mau dich, train 0).
    return train, val


def audit_eval_prompts(eval_prompts, train):
    """Prompt danh gia phai chua tung thay trong train.

    Kiem tra: khong prompt nao chua nguyen van 1 instruction
    cua train (neu khong, diem cao chi la hoc thuoc).
    """
    train_instructions = {d["instruction"] for d in train}
    for p in eval_prompts:
        for ins in train_instructions:
            assert ins not in p, f"Prompt danh gia trung train: {ins}"
    # [TRAINER] Trainer con kiem chat hon audit nay: doi chieu 6
    # prompt ca voi tap VAL (audit cua ban chi soi train) - van PASS,
    # ca 6 prompt deu chua tung thay o bat ky tap nao. Giu thoi quen
    # nay: bo eval chi co gia tri khi no do duoc khai quat hoa.
    print(f"Eval audit OK: {len(eval_prompts)} prompt deu chua tung "
          f"thay trong train.")


def verify_masking_all(tok):
    """Kiem chung masking -100 tren MOI mau (khong chi mau 0)."""
    for i, item in enumerate(DATA):
        ids, labels = encode_example(item, tok)
        prompt_len = len(tok(format_prompt(item["instruction"]),
                             add_special_tokens=False)["input_ids"])
        assert all(l == -100 for l in labels[:prompt_len]), \
            f"Mau {i} chua che het prompt!"
        assert labels[prompt_len:] == ids[prompt_len:], \
            f"Mau {i} label dap an sai!"
    # [TRAINER] Day 16 verify chi check mau 0 (dung de bai) - bai nay
    # lap qua MOI mau, dung gop y cua trainer. Chi phi vai dong code
    # nhung bat duoc loi encode o bat ky mau nao, khong chi mau dau.
    print(f"Masking OK tren tat ca {len(DATA)} mau.")


class SFTDataset(Dataset):
    """Dataset SFT: encode san toan bo mau luc khoi tao."""

    def __init__(self, items, tok):
        """Args: items la list dict mau, tok la tokenizer."""
        self.items = [encode_example(d, tok) for d in items]

    def __len__(self):
        """Tra ve so mau."""
        return len(self.items)

    def __getitem__(self, i):
        """Tra ve dict input_ids/labels cua mau thu i."""
        ids, labels = self.items[i]
        return {"input_ids": ids, "labels": labels}


def collate(batch, pad_id):
    """Dem batch ve cung do dai: pad token + nhan -100."""
    max_len = max(len(b["input_ids"]) for b in batch)
    input_ids, labels, attn = [], [], []
    for b in batch:
        pad = max_len - len(b["input_ids"])
        input_ids.append(b["input_ids"] + [pad_id] * pad)
        labels.append(b["labels"] + [-100] * pad)
        attn.append([1] * len(b["input_ids"]) + [0] * pad)
    return {"input_ids": torch.tensor(input_ids),
            "labels": torch.tensor(labels),
            "attention_mask": torch.tensor(attn)}


def count_trainable(model):
    """Tra ve (so tham so train duoc, tong so tham so)."""
    trainable = sum(p.numel() for p in model.parameters()
                    if p.requires_grad)
    total = sum(p.numel() for p in model.parameters())
    return trainable, total


def build_lora_model(tok, rank, target_modules):
    """Load GPT-2 moi tinh, gan LoRA, assert W goc bi dong bang.

    Ti le alpha/r giu co dinh = 2 (alpha = 2r) trong toan bo lab.
    """
    torch.manual_seed(SEED)
    base = AutoModelForCausalLM.from_pretrained(MODEL_DIR).to(DEVICE)
    base.config.pad_token_id = tok.pad_token_id
    config = LoraConfig(r=rank, lora_alpha=2 * rank, lora_dropout=0.05,
                        target_modules=target_modules,
                        task_type="CAUSAL_LM")
    model = get_peft_model(base, config)
    # [TRAINER] Kiem chung doc lap ca 3 rank: 12/12 tensor lora_B
    # bang 0 luc khoi tao, lora_A khac 0 -> delta W = 0 o step 0,
    # do bang lech logits so voi base = 0.00e+00 (model khong bi pha
    # truoc khi train). Va alpha = 2r dat o mot cho duy nhat nay nen
    # ti le alpha/r = 2 co dinh: doi rank la doi DUNG 1 bien, khong
    # dinh confound scale nhu trainer da canh bao o checklist.
    trainable, total = count_trainable(model)
    print(f"  r={rank} {target_modules}: train duoc {trainable:,} / "
          f"{total:,} tham so ({trainable / total:.2%})")
    # Assert: chi tham so LoRA (ten chua 'lora_') duoc train.
    bad = [n for n, p in model.named_parameters()
           if p.requires_grad and "lora_" not in n]
    assert not bad, f"W goc chua dong bang: {bad[:3]}"
    return model


@torch.no_grad()
def val_loss(model, tok, val_items):
    """Loss trung binh tren tap val (khong shuffle, khong train)."""
    model.eval()
    loader = DataLoader(SFTDataset(val_items, tok), batch_size=4,
                        collate_fn=lambda b: collate(b,
                                                     tok.pad_token_id))
    total, steps = 0.0, 0
    for batch in loader:
        batch = {k: v.to(DEVICE) for k, v in batch.items()}
        total += model(**batch).loss.item()
        steps += 1
    model.train()
    # [TRAINER] Gop y (khong phai loi): val chi co 4 mau -> val loss
    # la trung binh cua 4 batch don mau, mot thuoc do rat mong.
    # Chenh lech giua cac rank (0,016-0,035) nho hon do nhieu co the
    # co cua chinh thuoc do. Ket luan "r=16 tot nhat" dung tren so
    # da do, nhung lan sau nen chay 2-3 seed (hoac val 2 mau/kind)
    # de chac thu hang rank on dinh truoc khi chot.
    return total / steps


@torch.no_grad()
def generate(model, tok, prompt):
    """Sinh greedy 30 token theo dung template train."""
    model.eval()
    ids = tok(prompt, return_tensors="pt").to(DEVICE)
    out = model.generate(**ids, max_new_tokens=MAX_NEW_TOKENS,
                         do_sample=False,
                         pad_token_id=tok.eos_token_id)
    return tok.decode(out[0][ids["input_ids"].shape[1]:],
                      skip_special_tokens=True)


def eval_all(model, tok, title):
    """Sinh tren EVAL_PROMPTS, tra ve list dau ra (de doi chieu)."""
    print(f"===== {title} =====")
    outputs = []
    for p in EVAL_PROMPTS:
        text = generate(model, tok, p)
        outputs.append(text)
        print("PROMPT:", p.replace("\n", " / "))
        print("->", text)
    return outputs


def train_one_rank(tok, rank, train_data, val_data, target_modules):
    """Train 1 rank, tra ve dict (model, train_loss, val_loss, giay).

    Moi thu co dinh ngoai rank: seed, epoch, LR, batch, decoding.
    """
    model = build_lora_model(tok, rank, target_modules)
    loader = DataLoader(
        SFTDataset(train_data, tok), batch_size=BATCH_SIZE, shuffle=True,
        collate_fn=lambda b: collate(b, tok.pad_token_id),
        generator=torch.Generator().manual_seed(SEED))
    opt = torch.optim.AdamW(
        (p for p in model.parameters() if p.requires_grad),
        lr=LEARNING_RATE)
    # [TRAINER] Cho nay tranh dung loi kinh dien cua LoRA: truyen
    # model.parameters() tho vao optimizer. Loc theo requires_grad
    # nen Adam chi cap phat moment cho params LoRA - vua tiet kiem
    # bo nho, vua dam bao W goc khong bi cap nhat le.
    model.train()
    t0 = time.perf_counter()
    last_train_loss = None
    for epoch in range(EPOCHS):
        total_loss, steps = 0.0, 0
        for batch in loader:
            batch = {k: v.to(DEVICE) for k, v in batch.items()}
            out = model(**batch)
            out.loss.backward()
            opt.step()
            opt.zero_grad()
            total_loss += out.loss.item()
            steps += 1
        last_train_loss = total_loss / steps
        print(f"  r={rank} epoch {epoch + 1}: train loss = "
              f"{last_train_loss:.4f}")
    dt = time.perf_counter() - t0
    vl = val_loss(model, tok, val_data)
    print(f"  r={rank}: val loss cuoi = {vl:.4f} | train trong "
          f"{dt:.1f}s.")
    return {"model": model, "train_loss": last_train_loss,
            "val_loss": vl, "seconds": dt}


def adapter_size_mb(model, save_dir):
    """Luu adapter va tra ve dung luong (MB) cua thu muc."""
    model.save_pretrained(save_dir)
    total = 0
    for root, _, files in os.walk(save_dir):
        for f in files:
            total += os.path.getsize(os.path.join(root, f))
    return total / 1e6

    print(f"Co dinh: seed={SEED}, epoch={EPOCHS}, lr={LEARNING_RATE}, "
          f"batch={BATCH_SIZE}, alpha/r=2, target=c_attn, greedy.")

            res["model"], tok, f"EVAL r={rank} (c_attn)")
        results[rank] = res
    print("\n" + "=" * 72)
    print("BANG ABLATION")
    print("=" * 72)
    for rank, res in results.items():
        print(f"r={rank}: trainable={res['trainable']:,} | "
              f"train loss={res['train_loss']:.4f} | "
              f"val loss={res['val_loss']:.4f} | "
              f"{res['seconds']:.1f}s")
    best_rank = min(results, key=lambda r: results[r]["val_loss"])
    print(f"Rank tot nhat theo val loss: r={best_rank}.")
    print("\n" + "=" * 72)
    print(f"BAI 3 - Merge adapter r={best_rank} va kiem tra")
    print("=" * 72)
    best_model = results[best_rank]["model"]
    size_mb = adapter_size_mb(best_model, ADAPTER_DIR)
    print(f"Dung luong adapter r={best_rank}: {size_mb:.2f} MB "
          f"(so voi ~500 MB cua GPT-2 day du).")
    merged = best_model.merge_and_unload()
    merged_outputs = eval_all(merged, tok,
                              f"EVAL r={best_rank} SAU MERGE")
    same = sum(1 for a, b in zip(results[best_rank]["eval_outputs"],
                                 merged_outputs) if a == b)
    # [TRAINER] So sanh chuoi greedy 6/6 la tot; trainer kiem them o
    # muc logits: lech toi da 3,4e-04 - dung muc lam tron float32 khi
    # cong BA vao W. Neu cong sai chieu (bay Conv1D cua GPT-2) hoac
    # sai scale thi logits da lech han. Merge cua ban dung.
    print(f"Merge check: {same}/{len(EVAL_PROMPTS)} dau ra giong "
          f"het truoc/sau merge.")
    print("\n" + "=" * 72)
    print("MO RONG - Ablation target modules (c_attn + c_proj)")
    print("=" * 72)
    print("Chi doi target modules, giu nguyen rank tot nhat, seed, "
          "epoch, LR, dataset.")
    res_ext = train_one_rank(tok, best_rank, train_data, val_data,
                             ["c_attn", "c_proj"])
    trainable_ext, _ = count_trainable(res_ext["model"])
    print(f"r={best_rank} c_attn+c_proj: trainable={trainable_ext:,} | "
          f"train loss={res_ext['train_loss']:.4f} | "
          f"val loss={res_ext['val_loss']:.4f} | "
          f"{res_ext['seconds']:.1f}s (so voi c_attn: "
          f"val loss={results[best_rank]['val_loss']:.4f}).")
    eval_all(res_ext["model"], tok,

    print("\n" + "=" * 72)
    print("KET LUAN NHANH")
    print("=" * 72)
    print(f"- Rank tot nhat (val loss): r={best_rank}.")

    print("- Adapter chi vai MB so voi 500 MB model day du.")
