1 · Tóm tắt nhiệm vụ buổi sáng

Sáng nay (Day 41) đã làm 4 việc để biến hai lần chạy baseline (sàn n-gram + cấu hình A) thành quyết định có căn cứ:

  • Loss curve có 4 dạng: (1) hội tụ tốt — giảm đều, dốc chậm dần, để chạy hết; (2) plateau sớm — phẳng lì từ sớm, tăng LR hoặc xem lại dữ liệu; (3) diverge/spike — vọt lên, dao động mạnh, dừng ngay; (4) overfit — train giảm, val tăng, dừng ở checkpoint val thấp nhất. Luôn đọc cả train lẫn val — chỉ nhìn train loss là bẫy kinh điển.
  • Hai phép so sánh: khoảng cách n-gram ↔ A đo "giá trị của neural"; dao động seed đo ngưỡng ý nghĩa. Quy tắc vàng: chênh lệch PPL < dao động seed → nhiễu, không phải cải tiến. Và một phép so sánh không được làm: chọn checkpoint bằng tập test rồi báo cáo PPL trên chính tập đó.
  • Ma trận E0–E5: mỗi ô chỉ đổi một thứ, chạy rẻ trước đắt sau (E0 → E1 → E2 → E5 → E3 → E4), tổng ngân sách khoảng 3 GPU-giờ, mỗi ô có tiêu chí dừng viết trước khi chạy.
  • Nhiệm vụ giao cho tối nay: (1) đọc loss curve của baseline A, (2) lập bảng so sánh hai baseline, (3) khóa ma trận E0–E5, (4) chạy E5 trước E4.
PPL = exp(val loss)
chênh lệch PPL < dao động seed → NHIỄU, không phải cải tiến

2 · Nhiệm vụ tối nay — 4 phần việc

Phần A — Đọc loss curve của baseline A: phân loại bằng code, ghi nhận xét 3 dòng (45 phút)

Viết file classify_curve.py (Python thuần, không cần thư viện ngoài, không cần GPU). Script đọc log train dạng CSV (step,train_loss,val_loss), phân loại vào 1 trong 4 dạng theo quy tắc tường minh trong code, và in ra bằng chứng số + hành động xử lý. Code đầy đủ — bạn chỉ việc lưu file rồi chạy:

"""Phan loai loss curve — Day 41, nhiem vu 1.
Doc CSV log train: step,train_loss,val_loss (1 dong / checkpoint).
In: dang duong cong (1 trong 4 dang Day 41 §1), bang chung so,
va hanh dong xu ly.
Chay demo (sinh 5 duong cong mau, kiem tra bo phan loai):
    python classify_curve.py --demo
Chay tren log that cua ban (Day 34/35):
    python classify_curve.py train_A_seed42.csv
Quy tac phan loai (don gian, giai thich duoc — khong phai hop den):
  3. Diverge  — val loss co NaN/inf, hoac vot len gap >2 lan so voi
                gia tri thap nhat truoc do, hoac dao dong manh.
  4. Overfit  — val loss quay dau tang o nua sau (val cuoi cao hon
                val thap nhat >5%) trong khi train loss van giam.
  2. Plateau  — val loss gan nhu khong doi: (dau - cuoi)/dau < 5%.
  1. Hoi tu tot — cac truong hop con lai: val giam deu, doc cham dan.
Luu y: chi nhin train loss thi khong phan loai duoc dang 4 — script
bat buoc co ca hai cot train_loss va val_loss."""
import argparse, csv, math, random, sys

LABELS = {
    1: ("Hoi tu tot", "De chay het; ghi loss cuoi lam diem neo."),
    2: ("Plateau som", "Tang LR, hoac kiem tra du lieu co qua de / qua trung lap."),
    3: ("Diverge / spike", "DUNG NGAY — giam LR, bat gradient clipping, kiem tra lai."),
    4: ("Overfit", "Dung o checkpoint val thap nhat; xem lai ti le du lieu / epoch (Day 33)."),
}

def load(path):
    steps, tr, va = [], [], []
    with open(path, encoding="utf-8") as f:
        for r in csv.DictReader(f):
            steps.append(float(r["step"]))
            tr.append(float(r["train_loss"]))
            va.append(float(r["val_loss"]))
    assert len(steps) >= 10, "log can it nhat 10 dong"
    return steps, tr, va

def classify(tr, va):
    """Tra ve (dang, bang_chung)."""
    n = len(va)
    # 3. Diverge: NaN/inf hoac VOT DOT NGOT trong 1 buoc — phan biet
    # voi overfit (val tang DAN sau nhieu buoc). Chi so voi buoc
    # truoc do, khong so voi min lich su (tang dan cung vuot min).
    for i, v in enumerate(va):
        if math.isnan(v) or math.isinf(v):
            return 3, f"val loss = {v} o dong {i} (NaN/inf)"
        if i > n // 10 and i > 0:
            prev = va[i - 1]
            if (v > 2 * prev and v > prev + 0.5) or (v - prev > 1.0):
                return 3, f"val loss vot dot ngot {prev:.2f} -> {v:.2f} o dong {i}"
    # 4. Overfit: val cuoi cao hon min >5% va train van giam o nua sau
    vmin = min(va)
    half = n // 2
    train_down = tr[-1] < tr[half]
    if va[-1] > vmin * 1.05 and train_down:
        return 4, (f"val thap nhat {vmin:.2f} roi tang len {va[-1]:.2f} "
                   f"(+{(va[-1]/vmin-1)*100:.0f}%), train van giam {tr[half]:.2f} -> {tr[-1]:.2f}")
    # 2. Plateau: val gan nhu khong doi ca duong
    if (va[0] - va[-1]) / va[0] < 0.05:
        return 2, f"val loss gan nhu phang: {va[0]:.2f} -> {va[-1]:.2f} (giam {(va[0]-va[-1])/va[0]*100:.1f}%)"
    # 1. Hoi tu tot
    return 1, f"val giam deu {va[0]:.2f} -> {va[-1]:.2f}, doc cham dan, gan train loss"

def report(path):
    steps, tr, va = load(path)
    dang, bang_chung = classify(tr, va)
    ten, xu_ly = LABELS[dang]
    print(f"File: {path} | {len(steps)} checkpoint | step {steps[0]:.0f} -> {steps[-1]:.0f}")
    print(f"Train loss: {tr[0]:.2f} -> {tr[-1]:.2f} | Val loss: {va[0]:.2f} -> {va[-1]:.2f} (min {min(va):.2f})")
    print(f"Dang {dang}. {ten}")
    print(f"Bang chung: {bang_chung}")
    print(f"Xu ly: {xu_ly}")
    return dang

def gen_curve(kind, n=60, seed=7):
    """Sinh duong cong mau. Chi dung cho --demo, KHONG phai so that."""
    rnd = random.Random(seed)
    tr, va = [], []
    for i in range(n):
        x = i / (n - 1)
        if kind == 1:      # hoi tu tot: giam nhanh roi cham dan
            base = 2.0 + 4.5 * math.exp(-6 * x)
        elif kind == 2:    # plateau som: phang tu som
            base = 5.8 + 0.3 * math.exp(-8 * x)
        elif kind == 3:    # diverge: giam roi vot + dao dong
            base = 2.0 + 4.5 * math.exp(-6 * x) + (6.0 * (x - 0.55) ** 2 * 40 if x > 0.55 else 0)
        else:              # overfit: train giam, val quay dau tang
            base = 2.0 + 4.5 * math.exp(-6 * x)
        tr.append(base + rnd.uniform(-0.05, 0.05))
        if kind == 4:
            va.append(base + (3.0 * (x - 0.6) ** 2 * 8 if x > 0.6 else 0) + 0.15 + rnd.uniform(-0.05, 0.05))
        elif kind == 3:
            va.append(base + 0.15 + rnd.uniform(-0.3, 0.3))
        else:
            va.append(base + 0.15 + rnd.uniform(-0.05, 0.05))
    return tr, va

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("csv", nargs="?")
    ap.add_argument("--demo", action="store_true")
    args = ap.parse_args()
    if args.demo:
        print("DEMO — 5 duong cong mau (so minh hoa, khong phai so do cua de tai)")
        cases = [(1, "hoi tu tot"), (2, "plateau som"), (3, "diverge"),
                 (4, "overfit"), ("A", "duong A kieu Day 34 (giam nhanh, cham dan)")]
        ok = True
        for kind, ten in cases:
            k = 1 if kind == "A" else kind
            tr, va = gen_curve(k, seed=11 if kind == "A" else 7)
            path = f"/tmp/day41_lab/demo_{kind}.csv"
            with open(path, "w", newline="", encoding="utf-8") as f:
                w = csv.writer(f)
                w.writerow(["step", "train_loss", "val_loss"])
                for i, (t, v) in enumerate(zip(tr, va)):
                    w.writerow([i * 10, f"{t:.3f}", f"{v:.3f}"])
            dang, _ = classify(tr, va)
            expect = 1 if kind == "A" else kind
            mark = "OK " if dang == expect else "SAI"
            if dang != expect:
                ok = False
            print(f"[{mark}] {ten}: phan loai = dang {dang} ({LABELS[dang][0]}), ky vong dang {expect}")
        print("DEMO: bo phan loai dung 5/5" if ok else "DEMO: CO LOI — xem lai quy tac")
        sys.exit(0 if ok else 1)
    assert args.csv, "can <file.csv> hoac --demo"
    report(args.csv)

if __name__ == "__main__":
    main()

Việc của bạn trong phần này: (1) chạy python classify_curve.py --demo trước — script phải in DEMO: bo phan loai dung 5/5 (5 đường cong mẫu: 4 dạng + 1 đường kiểu A của Day 34; đây là số minh họa, không phải số đo của đề tài); (2) xuất log train thật của A (Day 34/35) ra CSV 3 cột rồi chạy script trên đó — ghi kết quả vào baseline_reading.md theo mẫu 3 dòng: dạng gì / bằng chứng là đoạn nào của đường cong / xử lý gì nếu chạy lại; (3) nếu log thật chưa có (số liệu Day 34/35 chưa nộp), ghi rõ "chưa có log thật — phân loại demo xong, chờ log" và đừng kết luận thay. Bài học sáng đã mô tả đường A của Day 34: loss ban đầu cao rồi giảm nhanh trong vài trăm bước đầu, sau đó dốc chậm dần — tức dạng 1, hội tụ tốt — nhưng mô tả đó chỉ được ghi nhận sau khi script của bạn phân loại đúng trên log thật của chính bạn.

💡 Vì sao quy tắc diverge so với bước trước, không so với min lịch sử? Overfit cũng làm val tăng vượt min cũ — nhưng tăng dần qua nhiều bước. Diverge thì vọt đột ngột trong một bước (hoặc thành NaN). So với bước trước đó tách được hai dạng này; so với min lịch sử thì overfit sẽ bị nhận nhầm thành diverge. Đây chính là khác biệt giữa "đọc đường cong" và "đọc một con số".

Phần B — Bảng so sánh hai baseline: sàn n-gram ↔ A, viết câu kết luận 1 dòng (30 phút)

Viết file compare_baselines.py (Python thuần). Script nhận PPL sàn n-gram (E0), PPL A (E1) và dao động seed (E5), tính khoảng cách + tỉ lệ, rồi áp quy tắc vàng để kết luận "neural có đáng tiền không". Code đầy đủ:

"""So hai baseline: san n-gram vs cau hinh A — Day 41, nhiem vu 2.
Doc: PPL san n-gram (E0) + PPL A (E1) + dao dong seed (E5).
In: khoang cach, ti le, va cau ket luan "neural co dang tien khong"
theo quy tac vang Day 41 §2: chenh lech < dao dong seed -> NHIEU.
Chay demo (so minh hoa, KHONG phai so do cua de tai):
    python compare_baselines.py --demo
Chay tren so that (dien so cua ban vao):
    python compare_baselines.py --ngram 12.40 --a 7.78 --seed-spread 0.30
So that lay tu: n-gram = ket qua ngram_floor.py (Day 40, du lieu that),
A = PPL held-out cua E1 (Day 40, chay du 200M token), seed-spread =
|delta PPL| cua E5 (compare_runs.py). O nao chua co so that thi de
trong — script tu choi ket luan thay vi bia so."""
import argparse, sys

def conclude(ngram, a, spread):
    dist = ngram - a
    ratio = (dist / ngram * 100) if ngram else 0
    print(f"San n-gram (E0): PPL {ngram:.2f}")
    print(f"Cau hinh A (E1): PPL {a:.2f}")
    print(f"Khoang cach n-gram - A: {dist:.2f} PPL ({ratio:.1f}% so voi san)")
    if spread is not None:
        print(f"Dao dong seed (E5): ±{spread:.2f} PPL")
    if dist <= 0:
        print("KET LUAN: A KHONG thang san n-gram — pipeline co van de. "
              "Dung lai, sua pipeline (tokenizer / du lieu / train) truoc, "
              "khong duoc chay E1–E5.")
        return "sai-pipeline"
    if spread is not None and dist < spread:
        print("KET LUAN: A thang san, NHUNG khoang cach nho hon dao dong seed "
              "-> chua ket luan duoc 'neural dang tien'. Chay them seed (E5) "
              "hoac kiem tra lai pipeline truoc khi di tiep.")
        return "chua-ket-luan"
    if ratio < 20:
        print("KET LUAN: A thang san mot cach kha nho (<20%). Pipeline da co "
              "gia tri, nhung nen kiem tra tokenizer / du lieu truoc khi chay "
              "E1–E5 — co the mo hinh moi chi hoc duoc thong ke tan suat.")
        return "thang-nhe"
    print("KET LUAN: A thang san ro ret. Kien truc neural 10M tham so nay "
          "DANG TIEN — pipeline da chung minh duoc gia tri, di tiep E1–E5.")
    return "dang-tien"

def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("--ngram", type=float)
    ap.add_argument("--a", type=float)
    ap.add_argument("--seed-spread", type=float, default=None)
    ap.add_argument("--demo", action="store_true")
    args = ap.parse_args()
    if args.demo:
        print("DEMO — so minh hoa (khong phai so do cua de tai):")
        print("  n-gram = 9,50 | A = 7,78 (PPL nen Day 34) | dao dong seed = 0,30 (nguong Day 40)")
        conclude(9.50, 7.78, 0.30)
        sys.exit(0)
    if args.ngram is None or args.a is None:
        print("Thieu so that. Dien: --ngram <PPL san E0> --a <PPL A E1> "
              "[--seed-spread <|delta PPL| E5>]")
        print("So nao chua co thi de trong — khong tu dat so thay the.")
        sys.exit(2)
    conclude(args.ngram, args.a, args.seed_spread)

if __name__ == "__main__":
    main()

Script kiểm tra — chạy python check_matrix.py matrix_E0_E5.csv, phải in PASS 6/6 mới được coi là khóa xong:

"""Kiem tra ma tran thi nghiem E0–E5 — Day 41, nhiem vu 3.
Doc file CSV ma tran (6 dong E0–E5), kiem tra:
  1. Du 6 o, dung thu tu chay: E0 -> E1 -> E2 -> E5 -> E3 -> E4
     (re truoc, dat sau; E5 chay truoc E4 vi khong co dao dong
     thi E4 khong ket luan duoc gi).

import csv, sys

ORDER = ["E0", "E1", "E2", "E5", "E3", "E4"]
REQUIRED = ["id", "thu_duy_nhat_thay_doi", "giu_nguyen", "cau_hoi",
            "chi_phi_uoc_tinh", "tieu_chi_dung"]

def check(path):
    errors = []
    with open(path, encoding="utf-8") as f:
        rows = list(csv.DictReader(f))
    header = rows[0].keys() if rows else []
    for col in REQUIRED:
        if col not in header:
            errors.append(f"thieu cot '{col}' trong CSV")
    if errors:
        return errors
    ids = [r["id"].strip() for r in rows]
    if ids != ORDER:
        errors.append(f"thu tu chay sai: co {ids}, can {ORDER} "
                      "(re truoc dat sau, E5 truoc E4)")
    if len(rows) != 6:
        errors.append(f"ma tran can dung 6 o, hien co {len(rows)}")
    for r in rows:
        tag = r["id"].strip()
        thay = r["thu_duy_nhat_thay_doi"].strip()
        if not thay:
            errors.append(f"{tag}: chua ghi 'thu duy nhat thay doi la ___'")
        elif any(s in thay for s in [",", ";", " va ", " + "]):
            errors.append(f"{tag}: doi nhieu hon 1 thu ('{thay}') — "
                          "tach thanh nhieu o, moi o 1 bien")
        # Luu y: "bat/tat" (vi du tied embeddings bat/tat) la MOT bien
        # nhi phan, khong phai hai thu doi — dau '/' khong tinh la loi.
        if not r["giu_nguyen"].strip():
            errors.append(f"{tag}: chua ghi giu nguyen nhung gi")
        if not r["cau_hoi"].strip():
            errors.append(f"{tag}: chua ghi cau hoi tra loi")
        if not r["chi_phi_uoc_tinh"].strip():
            errors.append(f"{tag}: chua ghi chi phi uoc tinh")
        if not r["tieu_chi_dung"].strip():
            errors.append(f"{tag}: chua viet tieu chi dung TRUOC khi chay")
    return errors

def main():
    assert len(sys.argv) == 2, "dung: check_matrix.py matrix_E0_E5.csv"
    errs = check(sys.argv[1])
    if not errs:
        print("PASS 6/6 o — ma tran khoa duoc: 1 bien/o, du chi phi, "
              "du tieu chi dung, dung thu tu E0->E1->E2->E5->E3->E4.")
        sys.exit(0)
    print(f"FAIL — {len(errs)} loi:")
    for e in errs:
        print(" - " + e)
    sys.exit(1)

if __name__ == "__main__":
    main()

Việc của bạn trong phần này: (1) lưu 2 file, chạy check_matrix.py — phải in PASS 6/6 o; (2) thử phá: sửa 1 dòng thành đổi 2 thứ (ví dụ E3 thành "kien truc, tang learning rate") rồi chạy lại — script phải báo FAIL đúng dòng đó, rồi sửa lại cho PASS; (3) bảng CSV này là phụ lục phương pháp của báo cáo — từ mai, mỗi thí nghiệm chạy đúng 1 dòng trong bảng, không thêm bớt, không đổi thứ tự (E0 → E1 → E2 → E5 → E3 → E4).

💡 Vì sao E5 chạy trước E4? E4 là ô đắt nhất (~50–110 phút) và là ô trả lời câu hỏi lớn nhất của đề tài: điểm tối ưu nằm ở A, B hay C. Nhưng nếu chưa biết dao động seed (E5) thì mọi chênh lệch PPL đo được ở E4 đều không kết luận được — có thể chỉ là nhiễu. Chạy E5 trước là mua "thước đo sai số" với giá ~8 phút × 2–3, để khỏi đốt 110 phút cho một kết quả không đọc được.

Phần D — Chạy E5 trước E4: seed thứ hai của A + quy tắc quyết định (45 phút)

Chạy lại đúng cấu hình A, đúng dữ liệu, đúng 200M token — chỉ đổi seed. Dùng lại run_A.sh của Day 40, chỉ đổi SEED=42 thành SEED=1337 (và đổi tên file log thành train_A_seed1337.jsonl). Trước khi chạy, viết ra câu "thứ duy nhất thay đổi là seed" và kiểm tra dữ liệu, phần cứng, tập đo đều giống hệt lần một — rồi chạy:

Việc của bạn trong phần này: (1) kiểm chứng logic quyết định trước bằng file demo: tạo baseline_results_demo.csv với 2 dòng E1-seed42 PPL 7,78 và E1-seed1337 PPL 7,91 (số demo, chỉ để kiểm tra script), chạy compare_runs.py (Day 40) — phải in |delta PPL| = 0.13 và kết luận "trong phạm vi nhiễu đo"; (2) chạy A seed 1337 thật trên GPU (nếu tối nay GPU bận: chạy trước bản dry-run 1M token để kiểm tra pipeline, ghi rõ "E5 dry-run xong, chạy đủ đang chờ GPU" — đừng giả vờ đã xong); (3) ghi |ΔPPL| thật vào baseline_reading.md và áp quy tắc: nếu |ΔPPL| > 0,3 thì chưa kết luận gì về B/C — xem lại pipeline trước đã; nếu ≤ 0,3 thì E4 được phép chạy từ Day 42, với ngưỡng ý nghĩa chính là con số |ΔPPL| này.

💡 Chạy E5 rẻ hay đắt? E5 tốn ~8 phút × 2–3 lần chạy A. Một lần chạy diverge để hết 110 phút (cấu hình C) đốt gấp ~14 lần một lần chạy A 8 phút — cho một kết quả đã đoán được từ phút thứ 5. Kỷ luật tối nay: không chạy cái đã biết sẽ hỏng, không chạy hết cái đã biết sẽ phẳng. Đó là biện pháp tiết kiệm năng lượng rẻ nhất của cả đề tài — không tốn một dòng code mới, chỉ tốn 5 phút nhìn đồ thị (Day 41 §1) và vài phút chạy E5.

3 · Tự kiểm tra nhanh

1. Train loss giảm đều nhưng val loss quay đầu tăng sau một thời gian — đó là dạng nào, xử lý ra sao?

Dạng 4, overfit: mô hình đang học thuộc lòng dữ liệu train, không khái quát được. Xử lý: dừng ở checkpoint có val loss thấp nhất, rồi xem lại tỉ lệ dữ liệu / số epoch (Day 33). Chỉ nhìn train loss thì sẽ tưởng mọi thứ vẫn tốt — bẫy kinh điển của Day 41 §1.

2. A và B chênh nhau 0,2 PPL, dao động seed (E5) là ±0,3. Kết luận gì?

Chưa kết luận được gì — chênh lệch 0,2 nhỏ hơn cả nhiễu đo (±0,3) nên rất có thể chỉ là nhiễu. Cần thêm lần lặp hoặc hiệu số lớn hơn 0,3 mới được tin. Đây là lý do E5 phải chạy trước khi so B/C — và trước E4.

3. Vì sao ma trận E0–E5 chạy theo thứ tự E0 → E1 → E2 → E5 → E3 → E4, chứ không chạy E4 ngay?

Vì rẻ trước, đắt sau — và vì E4 chỉ đọc được khi đã có dao động seed (E5). E0 bắt lỗi pipeline trong vài phút; E1/E2 rẻ (~8 phút × 2); E5 mua thước đo sai số; E3/E4 đắt (~50–110 phút) chạy cuối cùng, khi pipeline đã sạch và sai số đã biết. Chạy E4 ngay mà chưa có E5 thì kết quả không kết luận được gì.
